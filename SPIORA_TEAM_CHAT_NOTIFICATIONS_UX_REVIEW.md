# SPIORA Team Chat + Notifications — UX Review (PR #7)

**Дата:** 10 июля 2026  
**Область:** Team Chat, Notification Bell, toast-уведомления, demo-данные  
**Языки:** English (default), Русский

---

## Общая оценка

Интерфейс Team Chat и колокольчика уведомлений приведён к единому i18n-стилю, наполнен реалистичными demo-данными и готов к публичной демонстрации на обоих языках. Визуально модуль согласован с остальными локализованными разделами Spiora (Calendar, AI Workspace).

| Критерий | Оценка (1–5) | Комментарий |
|----------|--------------|-------------|
| Современность | 4 | Чистый чат-интерфейс, toast-стек, звук, deep links |
| Читаемость | 4 | Хорошая иерархия title → author → message |
| Плотность интерфейса | 4 | Компактный список уведомлений; чат не перегружен |
| Demo-эффект | 5 | 27 сообщений + 12 уведомлений создают «живую» команду |
| Качество английского | 4 | Естественные деловые формулировки |
| Качество русского | 4 | Корректный деловой русский, имена и бренды сохранены |
| Мобильная версия | 3 | Работает, но панель уведомлений узкая на малых экранах |
| Готовность к публичной демо | 4 | Готово с оговорками ниже |

---

## High Priority

| # | Замечание | Рекомендация |
|---|-----------|--------------|
| H1 | Нет отдельных «каналов» — один общий чат | Для демо достаточно; при расширении добавить sidebar с темами |
| H2 | Production client notifications ведут на `/new-formgrid-clients`, не на `/clients/DEMO-*` | В demo mode deep links уже ведут на demo routes; production — отдельная задача |
| H3 | Мобильная панель уведомлений может обрезать длинные тексты | Добавить `line-clamp` или scroll внутри item |

---

## Medium Priority

| # | Замечание | Рекомендация |
|---|-----------|--------------|
| M1 | Нет inline-редактирования сообщений в UI | Не блокер для демо; API edit отсутствует |
| M2 | Toast «Open section →» одинаков для всех типов | Можно типизировать CTA («Open chat», «Open task») |
| M3 | Demo calendar event IDs (`demo-notif-*`) не совпадают с calendar demo events | При клике открывается календарь с query param; событие может не подсветиться |
| M4 | Звук уведомлений без явного preview в demo tour | Добавить подсказку при первом toast |

---

## Low Priority

| # | Замечание | Рекомендация |
|---|-----------|--------------|
| L1 | Дублирующиеся иконки 📋 для task_new и task_status | Разные иконки для статуса vs новой задачи |
| L2 | В shared media контекст ссылок на сервере без locale | Контекст на EN по умолчанию; UI resolve на клиенте |
| L3 | Нет typing indicator / online presence в чате | Nice-to-have для «Slack-like» ощущения |
| L4 | Файл `visa-checklist-demo.pdf` — placeholder без реального PDF | Достаточно для демо; можно добавить stub-ответ API |

---

## Итог

**Готовность к публичной демонстрации: 4/5** — основной UX-путь (чат, уведомления, deep links, смена языка) работает. High-priority замечания не блокируют demo walkthrough.
